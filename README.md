# حجزني - منصة الحجوزات الفاخرة

منصة حجوزات فنادق حديثة تشبه أشهر منصات الحجوزات العالمية مثل Booking.com.

## المميزات

- 🔍 بحث متقدم حسب المدينة والتواريخ
- 🏨 قائمة فنادق فاخرة في الوطن العربي
- 📅 نظام حجز كامل مع حفظ الحجوزات
- 📱 تصميم متجاوب بالكامل (موبايل + ديسكتوب)
- 🌐 واجهة عربية بالكامل (RTL)
- ⭐ تقييمات وأسعار ومرافق

## التقنيات

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Lucide Icons

## التشغيل المحلي

```bash
npm install
npm run dev
```

ثم افتح [http://localhost:3000](http://localhost:3000)
